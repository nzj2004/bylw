# 毕业生招聘信息发布与管理系统开发计划

## 技术栈
- **前端**: Vue 3 + Element Plus + Vue Router + Pinia + Axios
- **后端**: Spring Boot 3 + Spring Security + MyBatis-Plus + JWT
- **数据库**: MySQL 8.0
- **构建工具**: Maven (后端) + Vite (前端)

## 数据库设计

### 1. 用户表 (sys_user)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| username | VARCHAR(50) | 用户名 |
| password | VARCHAR(100) | 密码(加密) |
| real_name | VARCHAR(50) | 真实姓名 |
| email | VARCHAR(100) | 邮箱 |
| phone | VARCHAR(20) | 电话 |
| role | TINYINT | 角色(1-管理员 2-运营 3-企业 4-求职者) |
| status | TINYINT | 状态(0-禁用 1-启用) |
| create_time | DATETIME | 创建时间 |
| update_time | DATETIME | 更新时间 |

### 2. 企业信息表 (company_info)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| user_id | BIGINT | 关联用户ID |
| company_name | VARCHAR(100) | 企业名称 |
| industry | VARCHAR(50) | 所属行业 |
| scale | VARCHAR(50) | 企业规模 |
| address | VARCHAR(200) | 企业地址 |
| description | TEXT | 企业简介 |
| logo_url | VARCHAR(200) | Logo地址 |
| status | TINYINT | 审核状态(0-待审核 1-已通过 2-已拒绝) |

### 3. 招聘信息表 (job_info)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| company_id | BIGINT | 企业ID |
| title | VARCHAR(100) | 职位标题 |
| category | VARCHAR(50) | 职位类别 |
| salary_min | INT | 最低薪资 |
| salary_max | INT | 最高薪资 |
| work_city | VARCHAR(50) | 工作城市 |
| experience | VARCHAR(50) | 经验要求 |
| education | VARCHAR(50) | 学历要求 |
| job_desc | TEXT | 职位描述 |
| requirements | TEXT | 岗位要求 |
| status | TINYINT | 状态(0-待审核 1-已发布 2-已拒绝 3-已下线) |
| view_count | INT | 浏览次数 |
| publish_time | DATETIME | 发布时间 |
| create_time | DATETIME | 创建时间 |

### 4. 简历表 (resume)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| user_id | BIGINT | 用户ID |
| real_name | VARCHAR(50) | 姓名 |
| gender | TINYINT | 性别 |
| birth_date | DATE | 出生日期 |
| phone | VARCHAR(20) | 电话 |
| email | VARCHAR(100) | 邮箱 |
| education | VARCHAR(50) | 最高学历 |
| school | VARCHAR(100) | 毕业院校 |
| major | VARCHAR(100) | 专业 |
| work_experience | TEXT | 工作经历 |
| project_exp | TEXT | 项目经验 |
| self_eval | TEXT | 自我评价 |
| attachment_url | VARCHAR(200) | 简历附件 |

### 5. 投递记录表 (application)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| job_id | BIGINT | 职位ID |
| resume_id | BIGINT | 简历ID |
| user_id | BIGINT | 求职者ID |
| status | TINYINT | 状态(0-待查看 1-已查看 2-感兴趣 3-不合适) |
| apply_time | DATETIME | 投递时间 |
| remark | VARCHAR(500) | 备注 |

## 关键功能说明

### 1. 权限控制
- 使用Spring Security + JWT实现无状态认证
- 基于角色的访问控制(RBAC)
- 前端路由守卫控制页面访问

### 2. 招聘信息审核流程
```
企业发布 → 运营审核 → 审核通过发布 / 审核拒绝退回
```

### 3. 管理员批量发布
- 支持Excel导入批量发布
- 提供批量发布表单页面
- 支持批量编辑和发布

### 4. 简历投递流程
```
求职者投递 → 企业查看 → 标记状态(感兴趣/不合适)
```
